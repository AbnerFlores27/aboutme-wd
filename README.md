# aboutme-wd

A personal site starter for Abner Flores.

## Customize it

- Edit the content and links in index.html.
- Tune colors, type, layout, and responsive behavior in styles.css.
- Keep the small mobile navigation behavior in script.js, or replace it with your own interactions.
- Replace hello@example.com with the email address you want visitors to use.

This is a dependency-free static site and can be published from any static hosting provider.
